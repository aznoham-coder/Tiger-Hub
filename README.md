# Tiger Hub

Panel Roblox au design minimaliste — build personnel de **aznoham-coder**.

- Script principal : `TigerHub.lua`
- Vérification de mise à jour : `version.json` (comparé à la version `3.7.1` du script)

## Chargement

Exécutez `TigerHub.lua` avec votre exécuteur Roblox. Le script vérifie automatiquement
les mises à jour via `version.json` sur ce repo.
